# Artwork and screenshots

- `Resources/AppIcon.png` and `docs/assets/app-icon.png`: the project's owl icon, generated with the built-in `image_gen` tool and refined from the project's own earlier owl concept.
- `hero.png` and `use-case.png`: AI-generated campaign illustrations made for this project. They express an intended local coding workflow, not hardware test evidence. No third-party product logos were used.
- `interface-off.png`, `interface-on.png`, and `interface-options.png`: captures of the actual native application. The visible interface is currently Chinese.
- `workflow.svg`: original code-native explanatory artwork.
- The menu-bar owl is original AppKit vector drawing code in `Sources/LidOnce/OwlMenuSymbol.swift`.

Campaign prompts are included in [prompts.json](assets/prompts.json). Keep illustration captions distinct from validation claims when reusing the campaign artwork. This project is distributed under the repository's MIT license.
