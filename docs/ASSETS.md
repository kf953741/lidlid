# Artwork and screenshots

- `Resources/AppIcon.png` and `docs/assets/app-icon.png`: the project's owl icon, generated with the built-in `image_gen` tool and refined from the project's own earlier owl concept.
- `zh-CN/hero-mobility.png` and `zh-CN/use-case-mobility.png`: AI-generated Chinese campaign artwork showing a developer carrying their laptop while leaving. The comparison shows open-laptop carrying with both hands and closed-laptop carrying with one hand. No edition badge or third-party product logos are used.
- `hero-mobility.png` and `use-case-mobility.png`: English text localizations of those Chinese illustrations, preserving the character, walking poses, laptop states, layout, and artwork. Each README uses its matching language. These are conceptual scenes, not hardware test evidence.
- `en/interface-{off,on,options}.jpg` and `zh-CN/interface-{off,on,options}.jpg`: captures of the actual native application in English and simplified Chinese. Each README uses the matching language.
- `workflow.svg` and `workflow.zh-CN.svg`: original code-native explanatory artwork in English and simplified Chinese.
- The menu-bar owl is original AppKit vector drawing code in `Sources/LidOnce/OwlMenuSymbol.swift`.
- `en/menu-states.png` and `zh-CN/menu-states.png`: code-native previews generated by `scripts/render-menu-symbols.swift` from the production vector drawing. Enlarged symbols and 18 pt samples show the closed-eye outline and wide-eye filled states on light and dark backgrounds.
- The bilingual DMG background is original code-native artwork in `scripts/dmg-background.swift`. The app icon and the system Applications folder remain actual Finder icons.
- `installer.jpg`: a capture of the actual DMG installation window in Finder.
- `en/demo-{off,on,reopened,options}.jpg` and `zh-CN/demo-{off,on,reopened,options}.jpg`: unmodified native app captures from LidLid 1.2.0 on macOS 27.0.1. The session-complete state was captured after a real close/reopen; the English version shows the same result after switching the UI language.
- `en/usage-demo.{mp4,gif}` and `zh-CN/usage-demo.{mp4,gif}`: silent, 20-second product walkthroughs. These edit together actual app captures and the existing AI-generated walking illustrations, with original captions and transitions. They are not continuous recordings of a person carrying a physical MacBook, and do not depict a recorded Codex or Claude Code session. All interface text comes from the corresponding native-language captures. No private conversations or terminal output are included.

To regenerate the walkthroughs on macOS with Swift and FFmpeg installed:

```sh
zsh scripts/make-usage-demo.sh
```

`scripts/render-usage-demo.swift` renders the original layouts from the committed source captures. `scripts/make-usage-demo.sh` encodes the MP4s and looping README GIFs. Intermediate scenes stay under `.build/usage-demo/`.

The current wordmarks are **盖盖 · LidLid** (Chinese) and **LidLid** (English). The latest brand-text edits are recorded in [rebrand prompts](assets/rebrand-prompts.json). Original generation prompts are retained in [English prompts](assets/mobility-prompts.json) and [Chinese prompts](assets/zh-CN/mobility-prompts.json); references to the former name in those records describe the historical inputs. Earlier artwork remains in Git history. Keep illustration captions distinct from validation claims when reusing the campaign artwork. This project is distributed under the repository's MIT license.
