# Artwork and screenshots

- **Brand palette**: Warm Ivory (`#FAF9F6`), Deep Slate (`#141923` / `#101319`), and LidLid Cobalt (`#2457C5` light / `#4C83FF`–`#7DA8FF` dark), shared across the macOS app (`PanelStyle.swift`), compatibility app, DMG installer background, App Store helper pages, and the official website (`website/public/site.css` with automatic light/dark appearance).
- `Resources/AppIcon.png` and `docs/assets/app-icon.png`: the project's blue plush guardian icon, generated with the built-in `image_gen` tool (documented in `Resources/BrandArtwork.json`).
- `zh-CN/hero-mobility.png` and `zh-CN/use-case-mobility.png`: the Chinese campaign uses the approved 3D cartoon character, with matching shots of the open laptop carried in both hands and the closed laptop carried in one hand.
- `hero-mobility.png` and `use-case-mobility.png`: the English versions use the same illustrations and localized typography. The website uses pre-cropped `700×700` `hero-scene-{zh,en}` and compressed WebP/JPEG copies. See the [cartoon campaign prompts](assets/cartoon-campaign.json).
- `en/interface-{off,on,options}.jpg` and `zh-CN/interface-{off,on,options}.jpg`: the graphite and cobalt native interface rendered in English and simplified Chinese with example session states.
- `workflow.svg` and `workflow.zh-CN.svg`: original code-native explanatory artwork in English and simplified Chinese.
- The menu-bar guardian is original AppKit vector drawing code in `Sources/LidOnce/GuardianMenuSymbol.swift`.
- `en/menu-states.png` and `zh-CN/menu-states.png`: code-native previews generated by `scripts/render-menu-symbols.swift` from the production vector drawing, showing Off, Closed-lid, Open-lid, Display awake, and Both lid modes on light and dark menu bars.
- The bilingual DMG background is original code-native artwork in `scripts/dmg-background.swift`. The app icon and the system Applications folder remain actual Finder icons.
- `en/demo-{off,on,reopened,options}.jpg` and `zh-CN/demo-{off,on,reopened,options}.jpg`: unmodified native app captures used to compose the 20-second silent walkthrough videos (`usage-demo.{mp4,gif}`).

To regenerate the menu-bar state previews or walkthroughs on macOS:

```sh
swiftc -parse-as-library Sources/LidOnce/GuardianMenuSymbol.swift scripts/render-menu-symbols.swift -framework AppKit -o .build/render-menu-symbols
.build/render-menu-symbols docs/assets/zh-CN/menu-states.png zh
.build/render-menu-symbols docs/assets/en/menu-states.png en
zsh scripts/make-usage-demo.sh
```

The current wordmarks are **盖盖 · LidLid** (Chinese) and **LidLid** (English). This project is distributed under the repository's MIT license.
