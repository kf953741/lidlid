任务还在跑，你已经要走了。

盖盖是一款轻巧的 MacBook 菜单栏工具。需要换个地方时，打开开关，再合上电脑，让正在进行的本机任务继续运行，不必托着一台开盖的笔记本走来走去。

为这一次合盖而开
开启后，本次合盖不休眠；重新打开盖子，会话自动结束。下次需要时，再开启一次。

不用插电，也不用外接屏
适合在不同工位之间移动、换到另一张桌子，或带着还在运行的任务出发。支持电池供电，不需要外接显示器。

任务继续，你也继续
适用于运行中的开发任务、编译、测试、渲染和下载，也适合需要让 Codex 或 Claude Code 继续工作的场景。盖盖控制的是 Mac 的睡眠状态，不会读取代码、接管 AI 工具或替你操作任务。联网任务仍需要网络连接。

给本次运行设个边界
可选 30 分钟、1 小时、2 小时、4 小时或 8 小时，也可以保持到再次开盖。设置了时长后，会话会在开盖或到时两者中较早发生时结束。

轻巧，也有清晰的状态
• 菜单栏小绒团，用睁眼与闭眼区分开启和关闭
• 电池供电且电量降至 10% 时自动结束
• 系统报告高温或过热状态时自动结束
• 支持登录时启动、简体中文和英文
• 无需账号，没有广告或追踪；偏好和诊断记录保存在本机

首次使用需独立安装免费的「盖盖兼容组件」，并在 macOS 中授权后台服务。商店主应用保持沙盒运行，不会索取管理员密码或自动安装组件。组件只在会话期间管理系统睡眠；需要主动睡眠时，请先关闭盖盖。

使用方法
1. 点开菜单栏里的小绒团。
2. 打开开关，确认显示「已开启」。
3. 合上电脑；再次开盖后，本次自动结束。

兼容与使用条件
需要 Apple Silicon（M 系列）MacBook 和 macOS 14 或更新版本，目前不支持 Intel Mac 或台式 Mac。请在未连接外接显示器时启用。

保持通风，放入包或保护套前先结束本次。盖盖不会使网络任务离线运行，也不会自动保存或管理其他应用的任务。
