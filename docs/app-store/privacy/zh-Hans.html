盖盖隐私政策

2026-11-02

盖盖（LidLid）由 Fei Kang 开发，是一个在 Mac 本机运行的菜单栏工具。应用无需账号，不向开发者上传使用数据，也没有广告或追踪 SDK。

免费兼容组件

支持商店分发的新版主应用可连接你独立安装并经 macOS 授权的免费兼容组件。组件只在本机接收盖盖的会话请求，读取睡眠、合盖、电量和温度状态，并临时管理系统睡眠设置。组件在管理员专用目录保存恢复原设置所需的版本号和一个布尔值；正常恢复后删除该记录，恢复失败时保留并重试。系统也可能保留组件运行诊断。

移除组件前，请先在组件窗口选择「恢复睡眠并移除服务」，再删除应用。请勿先删除恢复记录。组件不读取项目或 AI 对话，也不自动上传数据。

应用在本机处理的信息

盖盖保存你选择的界面语言和最长保持时间，读取合盖状态、电量、电源来源、系统温度状态和运行计时，用来管理你开启的本次会话。应用也会检查可能冲突的 Clamshell 合盖控制应用是否运行。

本机诊断记录包括开启、合盖、结束、恢复状态、错误和盖盖自身的进程标识。盖盖不读取你的项目、代码、文件内容、AI 对话或浏览记录。

数据不会自动上传

应用没有账号系统、广告、分析统计或开发者提供的网络服务，不会自动上传本机偏好、诊断记录或设备状态。它不使用这些信息识别你，也不进行跨应用或跨网站追踪。

本机保存期限与删除

偏好会保留到你修改或清除为止。诊断记录保存在本机；记录文件达到大小限制时会归档旧文件，归档不会自动上传，也没有自动删除期限。

要清除沙盒版的全部本机偏好和记录，请先退出盖盖，再通过访达的「前往文件夹」打开并移除 ~/Library/Containers/dev.kf.lidonce/。旧版非沙盒应用的记录可能保留在 ~/Library/Application Support/LidOnce/，偏好可能保留在 ~/Library/Preferences/dev.kf.lidonce.plist。仅删除应用不一定同时清除这些数据。

打开官网或外部链接

在应用中点击隐私政策或支持链接，会在浏览器中打开相应页面。官网没有访客分析 SDK、营销 Cookie 或登录功能。官网由 Vercel 托管；Vercel 会为页面交付、运行和安全处理 IP 地址、浏览器及请求信息，详见 Vercel 隐私说明。这些网站访问处理与应用在本机保存的信息不同。

下载与主动反馈

当前 DMG 下载由 GitHub 提供，适用 GitHub 隐私声明。如通过 App Store 下载或购买，相关处理由 Apple 按其适用条款完成。

如果你主动通过邮件发送联系邮箱、问题描述、机型、系统版本、日志或截图，我们会使用你提供的内容协助处理请求。邮件服务商也会按其规则处理邮件的传输与存储。请只发送处理问题所需的信息，不要包含密码、密钥或无关的私人内容。你可以通过同一邮箱请求更正或删除我们能够控制的反馈内容；第三方服务的数据处理和保留由其自身政策约束。
