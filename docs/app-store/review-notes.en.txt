LidLid is a sandboxed menu bar utility for Apple Silicon MacBooks on macOS 14 or later. A MacBook with a working lid sensor and battery is required. The Store edition is a free download with two non-consumable Apple in-app purchases: dev.kf.lidonce.trial7days (7-day Trial, free) and dev.kf.lidonce.lifetime (Closed-Lid Lifetime, US base price $4.99). No separate LidLid account is required, and there is no subscription or automatic renewal. Both purchases must accompany the first submission. Apple purchases and restore must be tested in the StoreKit sandbox before submission.

Full closed-lid functionality connects to an optional, free LidLid Compatibility app that the user independently obtains outside the Mac App Store. Full closed-lid operation, including on battery without an external display, requires this separate component. This dependency must be disclosed in the product description and first-use flow. The production component URL and final hardware validation must be supplied before submission. This document is preparation, not a claim of App Review acceptance.

Version 1.5 also provides a standalone open-lid keep-awake switch, using the public PreventUserIdleSystemSleep assertion. It allows display sleep and manual sleep, pauses when the lid closes, resumes after reopening/wake, and turns off on quitting. It is permanently free and requires no purchase, compatibility component or administrator permission. Each assertion has TimeoutActionRelease after 30 seconds and is renewed every 5 seconds while the UI remains responsive. This is independent of one-shot closed-lid sessions.

The Store app never installs the component, registers a root service, collects an administrator password, downloads executable code, or runs as root. Its setup button opens the independently installed component or the product support page. The component is a separate Developer ID-signed and notarized distribution, approved by the user through macOS Service Management. Do not submit while the production signed/notarized download is unavailable.

The sandboxed main app embeds a sandbox-inheriting unprivileged session worker. The only additional entitlement is a Team-ID-scoped application group for the named XPC connection. No temporary sandbox exceptions, network access, Accessibility, camera, microphone or broad file access are requested. Main app and component authenticate each other's Apple-anchored signing team and bundle identifiers.

The external service accepts only status, begin, renew, end and prepare-for-removal. It temporarily changes the system-wide SleepDisabled setting with fixed pmset arguments. Before mutation it records the original value in a private root-owned recovery journal. It restores and verifies that value after lid reopening, session expiry, safety cutoff, client disconnect, removal, or service restart recovery. A 30-second continuous-clock lease is renewed every 5 seconds. There is no general shell or command API. This external component is not embedded in the Store app.

Review flow once the final component URL and actual hardware test are complete:
1. Independently install the free component in /Applications. Open it, choose Install service, and approve macOS's background-service request in System Settings if necessary.
2. Open LidLid. It has no Dock icon; launch opens its menu-bar popover. Options changes language between English and Simplified Chinese.
3. Keep the lid open, disconnect external displays, and ensure battery is above 10% if on battery power. Start an expendable local task.
4. Enable the switch and wait for On, then close the lid. Battery power and no external display are supported by the intended feature.
5. Reopen. The session ends automatically; a subsequent lid close uses normal sleep unless explicitly enabled again.
6. To remove the external service, first disable LidLid, then choose Restore sleep & remove service in the compatibility app before deleting it.

Optional limits are 30 minutes, 1, 2, 4 and 8 hours, or until reopening. Battery <=10% on battery, serious/critical thermal pressure, sensor failure, and external display attachment end the session. Turn LidLid off before choosing manual Sleep. The global override also temporarily prevents manual sleep while a session is active.

LidLid does not read code, AI conversations or file contents, or operate coding assistants. Online tasks still need connectivity. There is no account, advertising, analytics, tracking or automatic diagnostic upload. Preferences, diagnostic records and the compatibility recovery record stay local. Privacy and support links are in Options; support is by email.

The closed-lid trial starts only after the free compatibility component is ready and the user explicitly claims the free 7-day Trial through Apple in-app purchase. Before that action, LidLid displays the duration, the restriction on starting new sessions after expiry, the StoreKit-localized lifetime price, and the free compatibility-component requirement. Only Apple-verified non-consumable transactions grant closed-lid access. Restore uses originalPurchaseDate and never restarts an ended trial. Lifetime access takes precedence while valid; revocation falls back to any remaining trial. Pending and unverified transactions do not unlock closed-lid mode. Open-lid keep-awake is always free, including before starting a trial, while products are unavailable, and after trial expiry.

Expiry only blocks a new arm command. It never sends a stop or open-awake-off command for an accepted session, whether it is armed with the lid open or already closed. Heartbeats and lease renewals continue. The current session ends by the original lid-reopen, duration, user-stop or safety rules. After it ends, starting another closed-lid session requires a valid entitlement.
