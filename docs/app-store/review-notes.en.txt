LidLid is a sandboxed menu-bar utility for Apple Silicon MacBooks running macOS 14+. No app account or login is required. Open-lid keep-awake is permanently free, independent of purchases or the external component. It prevents idle system sleep while allowing display sleep; it pauses on lid close/manual sleep, resumes on reopening/wake, and stops on quitting.

Closed-lid mode uses two Apple non-consumable products:
• dev.kf.lidonce.trial7days — “7-day Trial”, free.
• dev.kf.lidonce.lifetime — “Closed-Lid Lifetime”, US$4.99 base price.
The user explicitly claims the trial only after the free component is ready. Duration, expiry rules, localized lifetime price and component requirement are disclosed before claiming. Only verified Apple transactions unlock access. Restore uses originalPurchaseDate and does not restart an ended trial. There is no subscription or automatic renewal. Expiry blocks new closed-lid sessions; an accepted session continues under its original rules. Open-lid mode remains free even when products are unavailable.

Full closed-lid operation on battery without an external display requires the separately installed, free LidLid Compatibility app. The Store app does not install it, download executable code, request an administrator password or register a root service. The independent Developer ID component uses macOS Service Management with user approval. The component app is Developer ID signed and Apple notarized. For build 18, use the DMG link below. Component help in the setup window also opens the support page, where the same download is available. Download: https://lidlid.vercel.app/downloads/LidLid-Compatibility-1.0.1-macOS-arm64.dmg
Setup and removal: https://lidlid.vercel.app/en/support/#compatibility

The main app uses a sandbox-inheriting session worker and Team-ID-scoped App Group for authenticated XPC. It requests no temporary sandbox exceptions, network, Accessibility or broad file access. Both ends verify the signing team and bundle identity. The external service exposes only status/begin/renew/end/removal; it temporarily manages SleepDisabled using fixed pmset arguments, journals the original setting and restores it on session end or recovery. Its 30-second lease is renewed every 5 seconds; there is no general shell API. This component is not embedded in the Store app.

Availability: United States and mainland China.

Review steps:
1. Open the DMG and drag LidLid Compatibility to Applications. Open it, choose Install service and approve its background service in macOS. Wait for Compatibility component ready, then return to LidLid.
2. Open LidLid from the menu bar. Options offers English and Simplified Chinese. Test the free open-lid switch with the display asleep.
3. Disconnect external displays, keep battery above 10%, then claim the trial through Apple. Start a local test task, enable closed-lid mode, wait for On and close the lid.
4. Reopen: the session ends automatically. Another lid close sleeps normally unless re-enabled.
5. For lifetime access, click Unlock closed-lid access, then the blue Buy lifetime access + local price button in the separate window. Complete Apple confirmation. Test Restore Purchases.
6. To remove the component, disable LidLid, choose Restore sleep & remove service in the component, then delete it.

Sessions end on reopening, the selected limit, user stop, low battery (10% while on battery), serious/critical thermal pressure, sensor failure or external display attachment. Limits: 30 min, 1/2/4/8 h or until reopened. Disable closed-lid mode before manual Sleep, since its active override also prevents manual sleep.

LidLid does not read code, conversations or file contents, operate AI tools, or provide offline networking. No advertising, analytics, tracking or automatic diagnostic uploads. Preferences/diagnostics/recovery records stay local. Support: kf953741@gmail.com.
